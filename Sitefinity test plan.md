# Sitefinity test plan

All steps – Review UI and UX functionality, look for visual bugs and oddities

All steps – Test in these browsers and resolutions

- Desktop, 2560px
- Desktop, 1920px
- Desktop, 1366px
- Desktop Chrome or Edge
- Desktop Firefox
- Desktop Safari
- Mobile iPhone
- Mobile tablet / iPad
- Mobile responsive

## Testing steps

- Test sitebuild
  - Header and footer
  - Home page
  - Individual pages
  - Special pages
- Test Sitefinity base layout
  - Header and footer
  - Test additional templates
  - Test grid system
  - Test content alignment
- Test Sitefinity custom widgets
  - Create testing pages
  - Add widgets
  - Test properties
  - Test on backend and frontend
- Test Sitefinity default widgets
  - Content blocks
  - Navigation
  - Lists
  - Card
  - Events
  - Blogs
  - Forms
  - Search
- Test Sitefinity MVP dev complete
  - Test homepage
  - Test links and canonicals
  - Test critical and main features
  - Tier 1 pages
  - Tier 2 pages
  - Top navigation
  - Create widget guide page
  - Create style guide page
  - Forms
  - Global search
  - Run SEO spider tool, check for broken links, multiple H1s, incorrect DOM structure
