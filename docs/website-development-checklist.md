# Website development checklist

## Purpose

Use this checklist while building and configuring a website. It covers the common work that should happen before the separate launch checklist.

## Project setup

- [ ] Set up the required environments and document their important differences.
- [ ] Set up environment or content synchronization when the project uses it.
- [ ] Configure HTTPS and certificates.
- [ ] Configure and test backups for the website, database, media, and required settings.

## Site structure

- [ ] Create and review the sitemap or information architecture.
- [ ] Create the primary navigation and any utility or footer navigation.
- [ ] Create the header and footer.
- [ ] Create the homepage.
- [ ] Create the main page templates and content types.
- [ ] Configure useful `404` and server-error pages.
- [ ] Add redirects when URLs are changing.

## Responsive frontend

- [ ] Build and test the supported desktop, laptop, tablet, and phone layouts.
- [ ] Set up the required CSS and JavaScript build, bundling, and cache busting.
- [ ] Configure caching and test that it clears after content or code changes.

## SEO and Accessibility

- [ ] Add useful page titles and meta descriptions.
- [ ] Add canonical URLs.
- [ ] Add Open Graph or other sharing metadata when needed.
- [ ] Add favicons and application icons.
- [ ] Configure `robots.txt` and indexing rules for each environment.
- [ ] Create the XML sitemap when the site needs one.
- [ ] Configure the site search index when search is enabled.
- [ ] Review public pages with the [technical SEO review checklist](technical-seo-review-checklist.md).
- [ ] Review representative pages and important workflows with the [web accessibility review checklist](web-accessibility-review-checklist.md).

## Services and compliance

- [ ] Set up and test site email.
- [ ] Set up and test forms and other important integrations.
- [ ] Add analytics and tag management when required.
- [ ] Configure cookie consent and privacy controls when required.
- [ ] Confirm the licenses and usage rights for fonts, images, themes, plugins, and other assets.
- [ ] Set up basic uptime and error monitoring.

When development is complete, continue with the [website launch checklist](website-launch-checklist.md).
