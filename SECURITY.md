# Security reporting

## Purpose

Report suspected vulnerabilities in Web Development AI Skills Toolkit privately through the [Computerkick contact form](https://computerkick.com/contact/). Use the same form for support, update inquiries, and security questions.

## Report a vulnerability

Identify the toolkit by name and label your message as a security report. Include the affected version, a short description of the impact, and minimal reproduction steps when safe to share.

Do not post vulnerability details in public GitHub Issues or pull requests. Do not send credentials, tokens, customer data, private screenshots, or full evidence archives through the form. Start with a sanitized summary and arrange any sensitive follow-up with the maintainer.

Security findings about a website you reviewed belong with that website's owner, unless they also reveal a vulnerability in the toolkit itself. Only test systems you are authorized to review.

## Follow-up

This is a community project, with no guaranteed response or remediation time. Please coordinate disclosure with the maintainer before publishing details that could put users at risk.
